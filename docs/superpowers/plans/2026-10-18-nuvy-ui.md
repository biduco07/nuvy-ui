# nuvy-ui — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Transformar o protótipo do tema (scratchpad `tema/`) no repositório `biduco07/nuvy-ui`: fonte única dos tokens, gerador, conferência de contraste com teste, script de cópia, modelos do modo escuro e documentação.

**Architecture:** Node puro, sem dependências (ESM). `tokens.mjs` é a fonte; `scripts/gerar.mjs` escreve `dist/`; os testes (`node --test`) conferem o contraste, que `dist/` está em dia com os tokens e o comportamento do script de cópia e do `nuvy-tema.js`.

**Tech Stack:** Node ≥ 22 (`node:test`, `node:assert`), sem pacotes npm.

**Spec:** `docs/superpowers/specs/2026-10-18-tema-nuvytech-design.md` (versão 2)

## Global Constraints

- Marca única `nuvytech`; `dist/nuvytech/` (estrutura pronta para outra marca, sem uso agora).
- Estilo da spartan: `vega`; `--radius: 0.625rem`.
- Escuro por padrão; chave do `localStorage`: `nuvy-tema`, valores `escuro` | `claro`.
- Hover do primário: `color-mix(in oklab, var(--primary) 85%, var(--foreground))` em `:is([data-slot='button'], a[data-slot='badge']).bg-primary:hover`, dentro de `@media (hover: hover)`.
- Contorno base: `@apply border-border outline-ring;` (cor cheia).
- Mínimos: texto 4,5:1; borda de campo, foco, primary como estado e gráficos 3:1.
- Versão inicial `1.0.0`, no cabeçalho de todo arquivo gerado.
- Sem dependências npm; repositório privado; nada de push na `main` (o conteúdo entra por PR em rascunho).

## Review Focus

- `dist/` desatualizado em relação a `tokens.mjs` (alguém edita o token e esquece de gerar) → teste falha mostrando qual arquivo difere.
- Cópia para uma pasta que não é projeto (sem `package.json`) ou caminho errado → `copiar` recusa com mensagem clara e não cria pastas soltas.
- `localStorage` indisponível (modo privado, bloqueado) → `nuvy-tema.js` não lança erro e aplica o escuro.
- Valor desconhecido em `nuvy-tema` (ex.: `sistema`, `dark`) → trata como escuro.
- Arquivo copiado editado à mão no projeto → a próxima cópia sobrescreve só depois de avisar (mostra que o cabeçalho/versão mudou) — basta sobrescrever e imprimir a versão antiga e a nova.
